# v0.9.1 — USB gamepad settings

- Detect and test local USB controllers in Settings before connecting.
- Rebind Xbox buttons, D-pad directions and analog triggers with saved controller-model profiles.
- Diagnose incorrect Linux driver layouts using native input codes; no global A/X or LB/LT swap.
- Preserve fast input transitions, four stable forwarding slots, and release on focus loss,
  permission changes, unplugging and session shutdown.
- Windows host/viewer and Linux viewer roles are unchanged. Protocol 8 is unchanged.
- Bluetooth, Linux hosting and streaming performance changes are outside this release.

Build/test status and remaining hardware checks are recorded in
[the implementation progress report](../superpowers/plans/gamepad-progress.md).
